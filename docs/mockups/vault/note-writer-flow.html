Gates (in order)

Drain admission
  1. server not busy
  2. desktop heartbeat fresh
  3. no model call for 180 s
  4. mouse idle ≥ 180 s
  5. keyboard idle ≥ 180 s
  6. battery and GPU budget
Model work admissionModel jobs also need the model loaded (never loads it) and the resource budget. Capture notes need a vision-capable preset.
PreemptionAny interactive request or model unload aborts the in-flight call. The job is re-queued only if it hadn't committed.

Writers

Capture writerOne call: screenshot + app + window title + up to 20 matching note titles → edit operations.vault_capture_writer
Chat writerOne call: user text (code and quotes stripped) + reply + up to 20 matching titles → edit operations.vault_chat_writer
Tidy passOne call: title, types, lead, facts, plans → new lead. Skipped if the last revision is already a tidy.vault_tidy
Daily rollupNo model. Rebuilds the day note from that day's captures and chats.
Capture retentionNo model. Removes images past the age limit, then the oldest beyond 5 GB.
Edit applierMaps "the user" to the owner note. Drops unknown notes, bad titles and secrets. One revision per note.

One capture, end to end

  1. The scheduler fires (30 s cadence); the desktop app posts the screenshot.
  2. Intake drops duplicates, stores the PNG and writes a pending capture note.
  3. capture_note is queued (or the capture waits for a vision model).
  4. Every 20 s a drain checks the gates. With you active it stops at mouse idle.
  5. After 3 idle minutes the capture writer runs one model call.
  6. The applier writes entity facts; the capture note gets its Learned section.
  7. Follow-ups: daily_rollup:<day> and note_tidy for each touched entity.
  8. Retention later deletes the PNG; the note stays and says "image removed".

Why it gets things wrong

DuplicatesIt sees titles, not aliases or contents, and the search uses only app + window title. An entity visible on screen but missing from the list becomes a new note.
Wrong attributionNo note types or folders and no relations, so it can't tell project from tool from person.
Repeats / contradictsExisting fact rows are never shown, so it re-adds or conflicts with them.
Missed relationsNo links or neighbours, and nothing from the rest of the day.
