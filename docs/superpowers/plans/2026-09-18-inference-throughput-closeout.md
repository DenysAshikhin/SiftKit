## Global rules (every task)

- TypeScript only. Runtime Zod schemas own every boundary type; derive types with `z.infer`. Forbidden: `any`, type assertions, non-null assertions, namespace imports, schema-duplicating hand-written types, unvalidated IO. Handle missing values explicitly.
- TDD: failing test → minimal implementation → green → refactor. Never weaken a valid test. Update fixtures only where an interface you changed requires it.
- No commits, no worktrees, no edits to the running instance's engine, preset, or config. Temporary files only under `C:\tmp\rsx\throughput-closeout`; leave none behind.
- Never reintroduce: arithmetic averaging of rates, `outputTokens / requestDurationMs` as generation speed, reconstruction of a duration from a count and a rate, or visible-text token recounts as throughput evidence.
- Shared code to reuse, never duplicate: `packages/contracts/src/inference-throughput.ts` (schemas, `THROUGHPUT_MISMATCH_THRESHOLD_PCT`, `MIXED_MODEL_PRESET_LABEL`), `src/lib/inference-throughput.ts` (`readTabbyThroughput`, `observeTabbyThroughput`, `mergeInferenceThroughput`, `calculateThroughputRate`, `calculateTabbyReferenceRate`, `compareThroughputRate`, `emptyInferenceThroughput`, `unmeasuredInferenceThroughput`), `src/status-server/inference-throughput-audit.ts` (`auditInferenceThroughput(context, fold, publishedRates, logger?)`, `UNPUBLISHED_RATES`).
- Audit cardinality: one `request`-scope audit per logical model request (already inside `InferenceClient.chat`), one `published`-scope audit per completed observation at the boundary that owns it. GET handlers, replays, reconnects, and SSE re-sends never audit.
- Validation per task: `npm run build:test`, then `npm test -- <focused names>`, then `npm run typecheck` (it runs lint). Capture large output to the scratch directory and inspect exit codes plus the failing lines.
