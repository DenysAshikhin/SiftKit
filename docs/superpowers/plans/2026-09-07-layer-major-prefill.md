# Layer-major chunked prefill experiment

> Execute inline, TDD, no SiftKit/worktrees/commits. Authorized by user's instruction to explore other generic solutions if previous-chunk prefetch misses1,750tok/s. Context: `docs/analysis/2026-09-07-online-prefetch-worklog.md`.

**Goal:** Reuse each streamed expert across several attention chunks by applying the layer's MLP to their combined activations, without increasing physical attention chunk size, pinning expert residency, or using model-specific profiles.

**Architecture:** New grouped-prefill API receives actual available input tokens, prepares independent params per chunk, then iterates modules before chunks. Standard TransformerBlock splits attention/residual and MLP/residual into shared methods; attention runs causally in original-size chunks, MLP runs on concatenated chunk activations, then outputs split for next layer. Offloaded MoE naturally transfers each required expert once for the combined MLP. No speculative prediction or persistent expert cache is required. Arena and small pinned ring stay unchanged. Caller must actually supply the group; do not access future tokens outside supplied input or conceal an attention chunk-size change.

**Files:** `modules/transformer.py` (complete shared forward decomposition), `model/model_ls.py` (grouped execution), `model/model.py` (real API), tests `tests/test_chunked_prefill.py`, diagnostic runner `.scratch-staging/online-layer-major.py`. Only migrate eval/generator callers after correctness/performance proves the mechanism.
